ASTRA TACTICS v0.15 ONLINE 1:1

추가된 기능
- 싱글 AI 대전 그대로 유지
- 온라인 1:1 방 만들기 / 6자리 방 코드 참가
- 두 플레이어가 각자 저장한 30장 덱 선택
- 두 명 준비 완료 시 자동 시작
- 카드 사용 / 대상 지정 주문 / 결투 / 유닛 공격 / 영웅 공격 / 턴 종료 실시간 동기화
- 서버(Durable Object)가 덱 제한, 마나, 턴, 도발, 공격 가능 여부, 카드 효과를 검증
- 상대 손패 내용은 서버가 보내지 않고 장수만 표시
- 연결은 Cloudflare Durable Objects + WebSocket 사용

중요
이 버전은 기존처럼 Worker 편집창에 worker.js 하나만 붙여넣는 방식이 아닙니다.
Durable Object와 정적 Assets 설정이 필요해서 Wrangler 프로젝트로 1회 배포해야 합니다.

PC에서 최초 배포
1) Node.js 설치
2) 이 ZIP 압축 해제
3) 폴더에서 터미널 실행
4) npm install
5) npx wrangler login
6) npm run deploy

배포가 끝나면 표시되는 workers.dev 주소 하나만 친구와 공유하면 됩니다.
친구는 같은 링크에서 '온라인 1:1 대전' -> 방 참가 -> 6자리 코드 입력.

테스트
